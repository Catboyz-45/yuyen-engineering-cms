# คู่มือผู้ดูแลระบบ (ภาษาไทย)

## เริ่มใช้งานครั้งแรก

1. เปิด `/login` และใช้ชื่อผู้ใช้กับรหัสผ่านชั่วคราวที่ได้รับผ่านช่องทางปลอดภัย
2. ตั้งรหัสผ่านใหม่ที่ไม่ซ้ำกับบริการอื่น
3. สแกน QR ด้วยแอป Authenticator แล้วกรอกรหัส 6 หลักเพื่อยืนยัน
4. ดาวน์โหลด/จด Recovery Codes และเก็บใน password manager หรือที่ปลอดภัย ห้ามส่งในกลุ่มแชต แต่ละรหัสใช้ได้ครั้งเดียว

หากไม่มีโทรศัพท์ ให้เลือกใช้ Recovery Code ที่หน้า login หากไม่มีทั้ง TOTP และ Recovery Code ให้ติดต่อ Super Admin เพื่อยืนยันตัวตนและ reset 2FA

## บทบาท

- Editor: จัดการข้อมูลบริษัท แบนเนอร์ บริการ สินค้า ผลงาน ข่าว หมวดหมู่ และสื่อ
- Super Admin: ทำได้ทั้งหมด รวมจัดการบัญชี บทบาท reset password/2FA และดู audit

## การจัดการเนื้อหา

เลือกเมนูชนิดเนื้อหา แล้วกดเพิ่มหรือแก้ไข:

1. กรอกช่องที่จำเป็น ตรวจ slug, SEO title/description และข้อมูลติดต่อ
2. อัปโหลดภาพ JPEG/PNG/WebP ไม่เกิน 10 MB หรือ PDF ไม่เกิน 20 MB พร้อม alt text ที่อธิบายภาพ
3. บันทึก Draft และใช้ Preview ตรวจมือถือ/คอมพิวเตอร์
4. กด Publish เมื่อข้อมูลและสิทธิ์เผยแพร่ได้รับอนุมัติ
5. ใช้ Unpublish/Archive เมื่อต้องหยุดเผยแพร่ หรือ Move to trash เมื่อต้องการลบ

การเปลี่ยนแปลงจะแสดงบนเว็บไซต์ทันทีหลังบันทึก เมื่อ Unpublish หรือย้ายไปถังขยะ หน้านั้นจะหายจากเว็บไซต์ในคำขอถัดไป
หากเปลี่ยน slug ของรายการที่เผยแพร่แล้ว ระบบจะ redirect ลิงก์เดิมไปยัง slug ใหม่ให้อัตโนมัติ

วิธีนี้ใช้กับแบนเนอร์ บริการ สินค้า ผลงาน และข่าว สำหรับสินค้าให้ตรวจยี่ห้อ รุ่น ประเภท BTU สเปก ราคา/ข้อความสอบถาม และ PDF; สำหรับผลงานห้ามเปิดเผยชื่อลูกค้าหรือสถานที่ละเอียดหากยังไม่ได้รับอนุญาต

## ข้อมูลบริษัทและแบนเนอร์

ตรวจชื่อบริษัท ที่อยู่ เวลาทำการ โทรศัพท์ อีเมล LINE Facebook และพิกัดแผนที่กับเจ้าของก่อนบันทึก แบนเนอร์ควรมีภาพที่บริษัทมีสิทธิ์ใช้ ข้อความสั้น และ CTA ที่ไปยังหน้าในระบบหรือ URL ที่ตรวจแล้ว

เมนู "ข้อมูลบริษัท" แก้ได้ทั้งหมดจากหลังบ้านโดยไม่ต้องแก้โค้ด:

- ข้อความหน้าเกี่ยวกับเรา: คำอธิบายบริษัท ประวัติ วิสัยทัศน์ พันธกิจ และคุณค่าของเรา
- ช่องทางติดต่อ: ที่อยู่ โทรศัพท์ อีเมล LINE Facebook Google Maps และเวลาทำการ
- โลโก้บริษัท: แสดงที่หัวเว็บและท้ายเว็บแทนไอคอนเริ่มต้น ใช้ไฟล์สี่เหลี่ยมจัตุรัสพื้นหลังโปร่งใสหรือพื้นขาว
- รูปบริษัท: สูงสุด 12 รูป รูปแรกเป็นภาพหลักของหน้าเกี่ยวกับเรา รูปที่เหลือแสดงเป็นแกลเลอรี ใส่ข้อความอธิบายรูปทุกรูป
- SEO title และ SEO description: ใช้เป็นชื่อและคำอธิบายของหน้าแรกในผลการค้นหา SEO description ยังเป็นคำอธิบายเริ่มต้นของหน้าอื่นที่ไม่ได้กำหนดเอง ชื่อที่แสดงของบริษัทจะต่อท้ายชื่อทุกหน้า
- ข้อความบนหน้าเว็บ: ป้ายและหัวข้อหน้าแรก จุดเด่น 3 ข้อ ขั้นตอนการทำงานสูงสุด 6 ขั้น หัวข้อของแต่ละส่วน ข้อความชวนติดต่อ หัวข้อหน้าเกี่ยวกับเรา คำนำหน้ารายการ (บริการ สินค้า ผลงาน ข่าวสาร ติดต่อเรา) และคำโปรยท้ายเว็บ ช่องหัวข้อต้องกรอกเสมอ ช่องอื่นเว้นว่างเพื่อซ่อนได้ กด Enter ในหัวข้อเพื่อขึ้นบรรทัดใหม่ ข้อความทั้งหมดแสดงเป็นตัวอักษรธรรมดา ไม่รองรับ HTML

ช่องที่เว้นว่างจะถูกซ่อนจากหน้าเว็บ เช่น ลบเบอร์โทรออกแล้วปุ่ม "โทรหาเรา" จะหายไป ก่อนบันทึกข้อมูลบริษัทครั้งแรก หน้าเว็บจะแสดงป้าย "ข้อมูลตัวอย่างสำหรับการพัฒนาระบบ" (บนเซิร์ฟเวอร์จริงจะไม่แสดงเบอร์หรืออีเมลตัวอย่าง) ป้ายนี้หายไปเองหลังบันทึกครั้งแรก การบันทึกมีผลกับหน้าเว็บทันที ถ้ามีผู้ดูแลคนอื่นแก้ข้อมูลก่อน ระบบจะให้โหลดหน้าใหม่แทนการเขียนทับ ลิงก์บริการในท้ายเว็บดึงจากบริการที่เผยแพร่ 3 รายการแรกตามลำดับที่ตั้งไว้

- ลิงก์ LINE, Facebook และ Google Maps ต้องขึ้นต้นด้วย `https://`
- ลิงก์ปุ่มของแบนเนอร์ใช้ได้ทั้ง `https://...` หรือหน้าในเว็บไซต์ที่ขึ้นต้นด้วย `/` เช่น `/contact`
- ช่อง "ลิงก์ฝังแผนที่" รับเฉพาะลิงก์ฝังแผนที่ของ Google: เปิด Google Maps > ค้นหาที่ตั้งบริษัท > แชร์ > ฝังแผนที่ > คัดลอกเฉพาะค่าใน `src="..."` ซึ่งขึ้นต้นด้วย `https://www.google.com/maps/embed?pb=`

## นโยบายเว็บไซต์ (เฉพาะ Super Admin)

หน้านโยบายความเป็นส่วนตัว นโยบายคุกกี้ และเงื่อนไขการใช้เว็บไซต์เริ่มเป็น **ฉบับร่าง** มีป้ายแจ้งบนหน้า และไม่ให้เครื่องมือค้นหาเก็บหน้า เมนู "นโยบายเว็บไซต์" ใช้กรอกข้อมูลที่บริษัทต้องยืนยันเอง:

- อีเมลรับคำร้องเรื่องข้อมูลส่วนบุคคล: ต้องมีผู้รับผิดชอบตอบจริง แยกจากอีเมลติดต่อทั่วไปได้
- ผู้ให้บริการและพื้นที่จัดเก็บข้อมูล: ผู้ให้บริการโฮสติ้ง ฐานข้อมูล ที่เก็บรูป/PDF และสำเนาสำรอง พร้อมประเทศที่เก็บข้อมูล หนึ่งรายการต่อบรรทัด
- ระยะเวลาเก็บข้อมูล: ระยะเวลาเก็บสูงสุดของประวัติระบบ (อย่างน้อย 180 วัน) บันทึกโฮสติ้ง ข้อมูลติดต่อ และสำเนาสำรอง

ข้อมูลที่กรอกจะแสดงบนหน้านโยบายทันทีแม้ยังเป็นฉบับร่าง เปิดลิงก์ในหน้าหลังบ้านเพื่อตรวจหน้าจริง เมื่อผู้รับผิดชอบข้อมูลหรือที่ปรึกษากฎหมายตรวจครบทั้ง 3 หน้าแล้ว ให้ติ๊ก "รับรองและประกาศใช้นโยบาย" แล้วบันทึก ระบบต้องการข้อมูลครบทั้ง 3 ช่องจึงรับรองได้ เมื่อรับรองแล้วป้ายฉบับร่างจะหายไป หน้านโยบายแสดงวันที่ประกาศใช้ และถูกเพิ่มใน sitemap เอาติ๊กออกเพื่อกลับเป็นฉบับร่าง การรับรอง การยกเลิก และการแก้ไขทุกครั้งถูกบันทึกในประวัติการทำงาน

ข้อความส่วนอื่นของนโยบายอธิบายการทำงานของระบบ เช่น คุกกี้ล็อกอินและแผนที่ จึงแก้ผ่านนักพัฒนาเท่านั้น เมื่อนักพัฒนาแก้ข้อความ ฉบับของนโยบายจะเปลี่ยนและหน้านโยบายจะกลับเป็นฉบับร่างเองจนกว่าจะรับรองใหม่ เพื่อไม่ให้ข้อความที่ยังไม่ได้ตรวจแสดงเป็นฉบับรับรอง

## ยี่ห้อ ประเภทสินค้า และหมวดข่าว

จัดการได้จากเมนู "หมวดหมู่" ช่องลิงก์ (slug) ใช้ภาษาอังกฤษตัวพิมพ์เล็ก ตัวเลข และขีดกลาง ระบบไม่อนุญาตให้ย้ายหมวดที่ยังมีสินค้าหรือข่าวใช้อยู่ไปถังขยะ ให้ย้ายรายการเหล่านั้นไปหมวดอื่นก่อน

## รูปภาพและเอกสาร

- ใช้ไฟล์ต้นฉบับที่ชัดเจนและบริษัทมีสิทธิ์เผยแพร่
- หลีกเลี่ยงข้อมูลส่วนบุคคล ป้ายทะเบียน ใบหน้า เอกสารลูกค้า หรือพิกัดงานที่อ่อนไหว
- เมื่อเปลี่ยนไฟล์ ให้ตรวจ Preview และ public page หลัง Publish
- ระบบเก็บสื่อที่ไม่ใช้งานตามระยะ retention; ห้ามลบไฟล์ตรงจาก bucket

## ถังขยะ

รายการในถังขยะกู้คืนได้ภายใน 30 วัน เลือก "กู้คืน" เพื่อคืนรายการ รายการที่กู้คืนจะกลับมาเป็นฉบับร่าง ต้องตรวจและกดเผยแพร่อีกครั้ง การลบถาวรทำได้เฉพาะ Super Admin และย้อนกลับไม่ได้ ต้องยืนยัน backup/ความสัมพันธ์ของรูปก่อนดำเนินการ

## จัดการผู้ดูแล

Super Admin เพิ่มบัญชีโดยกำหนดชื่อผู้ใช้ ชื่อแสดง และบทบาท ระบบแสดงรหัสผ่านชั่วคราวครั้งเดียว ส่งให้เจ้าของบัญชีแบบส่วนตัว การเปลี่ยนบทบาท ปิดบัญชี reset password หรือ reset 2FA จะยกเลิก session เดิม

- ย้ายบัญชีไปถังขยะจากเมนู ⋯ ของบัญชีนั้น ผู้ใช้จะออกจากระบบทันทีและเข้าสู่ระบบไม่ได้ บัญชีจะอยู่ในเมนู "ถังขยะ" 30 วัน
- กู้คืนบัญชีได้จากเมนู "ถังขยะ" ภายใน 30 วัน บัญชีที่กู้คืนจะอยู่ในสถานะปิดใช้งาน ต้องกดเปิดใช้งานจากหน้าผู้ดูแลระบบอีกครั้ง
- ลบบัญชีถาวรได้เฉพาะบัญชีที่อยู่ในถังขยะ โดยกดลบถาวรในเมนู "ถังขยะ" แล้วยืนยัน ระบบจะลบชื่อ ชื่อผู้ใช้ รหัสผ่าน และ 2FA ทิ้ง แต่ยังเก็บประวัติ audit ไว้ในชื่อ "ผู้ดูแลที่ถูกลบ" เมื่อครบ 30 วันงาน retention จะลบถาวรให้อัตโนมัติ
- ระบบไม่อนุญาตให้ปิด ลดสิทธิ์ หรือย้าย Super Admin คนสุดท้ายไปถังขยะ และไม่อนุญาตให้เปลี่ยนบทบาท สถานะ หรือย้ายบัญชีของตัวเอง ต้องให้ Super Admin อีกคนดำเนินการ

## เปลี่ยนรหัสผ่านของตัวเอง

กดชื่อบัญชีที่มุมซ้ายล่างของเมนู (บนมือถืออยู่ในเมนูด้านข้าง) เพื่อเปิดหน้า "ตั้งค่าบัญชี" กรอกรหัสผ่านปัจจุบันและรหัสผ่านใหม่ที่ไม่ซ้ำรหัสเดิม อุปกรณ์อื่นที่เข้าสู่ระบบด้วยบัญชีนี้จะถูกออกจากระบบ หากกรอกรหัสผ่านปัจจุบันผิดหลายครั้ง ระบบจะพักการลองชั่วคราวเหมือนตอนเข้าสู่ระบบ

## บัญชีถูกล็อกชั่วคราว

หากกรอกรหัสผ่าน รหัส 2FA หรือ Recovery Code ผิดหลายครั้ง ระบบจะระงับการลองชั่วคราว และเพิ่มเวลาขึ้นเมื่อผิดซ้ำ (สูงสุดประมาณ 2 ชั่วโมงตามค่าเริ่มต้น) ให้รอแล้วลองใหม่ หรือให้ Super Admin reset password หรือ reset 2FA ซึ่งจะปลดล็อกบัญชีด้วย

## Dashboard และ Audit

Dashboard แสดงจำนวนและสถานะเนื้อหา ใช้ Audit ตรวจผู้กระทำ เวลา action เป้าหมาย และผลสำเร็จ/ล้มเหลว ห้ามใช้ audit เพื่อเก็บรหัสผ่านหรือข้อมูลลับ หากพบ login failure ผิดปกติให้แจ้งผู้รับผิดชอบระบบ

## เหตุฉุกเฉิน

คำสั่ง `RECOVERY_ADMIN_USERNAME=<username> RECOVERY_TEMPORARY_PASSWORD=<รหัสชั่วคราวอย่างน้อย 12 ตัว> npm run auth:recover` ใช้เฉพาะผู้ดูแล server หลังยืนยันตัวตนตามขั้นตอนบริษัท คำสั่งจะ revoke sessions และบังคับตั้ง password/2FA ใหม่ เหตุฐานข้อมูลหรือไฟล์เสียหายให้หยุด write และทำตาม `docs/DEPLOYMENT.md` ห้ามแก้ฐานข้อมูล production ด้วยมือ

## ข้อจำกัดการปฏิบัติงาน

ระบบไม่ใช่ ecommerce, ไม่มีการรับชำระเงิน/สต็อก/บัญชีลูกค้า และไม่มี contact form storage ข้อมูลจริงทุกชิ้นต้องมีผู้รับผิดชอบบริษัทอนุมัติก่อนเผยแพร่
